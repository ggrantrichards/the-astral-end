# The Astral End: a field guide

The website for [The Astral End](https://modrinth.com/mod/the-astral-end), a Minecraft mod. Live at https://ggrantrichards.github.io/the-astral-end/

Built from the mod's test runs: the cut-outs and models are drawn by the mod's own tools, the other pictures are in-game screenshots.
